# 🍅 스몰 힐링 뽀모도로

집중 타이머(뽀모도로) + 감정 일기장 + AI 일기 Q&A 웹앱

- **앱 바로가기**: https://script.google.com/macros/s/AKfycbyRSqnP3ue5qLB5dtybYkHNt3F0RrRUVN7OMgj9xSQF14-0rX5djwXyMF4GvGdsgsjY/exec (구글 로그인 필요)

## 주요 기능
- 뽀모도로 집중 타이머와 완료 기록
- 감정·에너지를 함께 남기는 일기장
- "1년 전의 나는 어땠어?"처럼 내 일기에 대해 물어보는 AI (Google Gemini)
- 회원가입 / 로그인 / 아이디·비밀번호 찾기

## 만든 방법
- 화면 디자인: Google Stitch
- 서버 + 데이터 저장: Google Apps Script + Google Sheets (`gas-backend` 폴더)
